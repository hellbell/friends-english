# Friends 영어공부

내 영상(+영어 자막)이나 유튜브 영상으로 문장 단위 듣기, 따라 말하기, 받아쓰기를 하는 웹앱입니다.
맥미니에서 서버를 켜 두면 아이폰·아이패드·노트북 어디서나 같은 진도와 보관함으로 공부할 수 있습니다.
GitHub Pages 버전은 맥 서버 없이 YouTube와 기기에서 선택한 영상으로 공부할 수 있으며, 비밀번호로 잠겨 있습니다.
Python 3 표준 라이브러리만 사용합니다 (잠긴 Pages 빌드의 암호화에만 Deno를 씁니다).

## 온라인에서 사용

**https://hellbell.github.io/friends-english/**

처음 여는 기기에서는 비밀번호를 입력합니다. **이 기기에서 로그인 유지**를 켜 두면 그 브라우저는 다음부터 묻지 않습니다. 아이폰 홈 화면에 추가한 앱은 Safari와 저장소가 따로라서 한 번 더 로그인합니다. 기기 하나만 로그아웃하려면 주소 끝에 `#lock`을 붙여 엽니다(`…/friends-english/#lock`). 비밀번호를 바꿔 배포하면 모든 기기가 다시 로그인해야 합니다.

- 선택한 **Latent Space 11편**의 영어 대본과 GPT 한국어 번역을 프로젝트에 포함했습니다. 추천 목록의 **Latent Space 선택 11편**에서 찾을 수 있으며, 문장을 눌러 구간 재생·반복을 할 수 있습니다.
- 2026-11-03에 11편의 영어 자막을 내려받아 총 **11,701개 구간**을 GPT로 번역했습니다. 한영 SRT의 구간 수와 밀리초 단위 시작·종료 시각을 검증했습니다. 저장소의 다음 배포부터 온라인 페이지에도 반영됩니다.
- 준비된 AI 영상에 영어 대본과 GPT 한국어 번역을 연결했습니다. 영상은 YouTube 공식 플레이어에서 재생하고, 대본 문장을 누르면 그 구간으로 이동합니다.
- **추천 영상**에서 주제·난이도·길이·한영 대본 준비 여부로 찾고 바로 공부할 수 있습니다. BBC Learning English, VOA Learning English, TED-Ed, 3Blue1Brown의 공개 피드에서 채널별 최신 영상 최대 10개를 더합니다. 난이도는 채널·영상에 따른 추정치입니다.
- 추천 목록은 GitHub Actions에서 매일 갱신합니다. 앱 안의 검색은 이 목록을 검색하며, **YouTube에서 더 찾기**는 YouTube 전체 검색을 새 창으로 엽니다. 실시간 YouTube 전체 검색이나 GPT 추천 API를 호출하지 않으며 API 키가 필요 없습니다.
- 새 추천 영상에 학습 대본이 자동으로 생기지는 않습니다. YouTube CC, **시작 A → 끝 B → A–B 반복**을 쓰거나, 영어·한국어 SRT/VTT/SMI 파일을 열어 문장 학습을 연결하세요. 추가 자막 파일은 현재 세션에서만 유지됩니다. 새 자막의 GPT 번역도 별도 준비가 필요합니다.
- 보관함은 아래 **보관함 동기화**를 켜면 모든 기기에서 같이 보입니다. 진도·추가한 YouTube 목록은 **현재 브라우저**에 저장됩니다. 다른 기기로 옮길 때는 보관함의 **학습 백업 내보내기 → 백업 가져오기**를 사용합니다. 기존 보관함은 유지하며 새로운 항목만 병합하고, 겹치는 진도는 현재 기기의 것을 유지합니다. 백업에는 영상 파일이 포함되지 않습니다.
- 맥 서버에서 내보낸 준비된 AI 영상의 진도·보관함은 온라인 YouTube 영상 ID로 변환됩니다. 브라우저 데이터를 지우거나 다른 브라우저·주소를 쓰면 저장 내용이 이어지지 않으므로 먼저 백업하세요.

### 보관함 동기화

저장한 문장·단어(보관함)를 온라인 버전과 맥 서버 등 모든 기기가 같이 씁니다. 한 기기에서 지운 항목은 다른 기기에서도 지워집니다. 진도(이어보기)는 동기화하지 않습니다.

- GitHub 비공개 저장소 **hellbell/friends-english-sync**의 `notes.json` 하나를 주고받습니다. 앱을 열 때, 앱으로 돌아올 때, 저장·삭제하고 1.5초 뒤에 동기화하며, 보관함 탭의 **지금 동기화**로도 할 수 있습니다. 여러 기기가 동시에 저장하면 다시 받아 합칩니다.
- 처음 한 번 이 맥에서 `python3 build_pages.py --set-sync`를 실행합니다. 비공개 저장소를 만들고, 토큰 만들기 페이지를 엽니다(Contents 쓰기·만료 없음은 채워져 있고, **Repository access → Only select repositories**에서 이 저장소만 고릅니다). 붙여넣은 토큰은 맥 서버용 `~/Library/Application Support/FriendsEnglish/notes-sync`와 온라인 버전용 비밀값 `NOTES_SYNC`에 저장됩니다. 온라인 버전은 다음 배포부터, 맥 서버는 앱을 새로 고치면 켜집니다.
- 토큰은 잠긴 앱 안에 암호화되어 들어갑니다. 사이트 비밀번호를 아는 사람은 이 토큰으로 동기화 저장소 하나를 읽고 쓸 수 있습니다. 토큰이 샜다고 생각되면 GitHub에서 지우고 `--set-sync`를 다시 실행하세요. `notes.json` 자체는 암호화하지 않습니다(비공개 저장소).

### Friends 등 내 영상: Dropbox에서 재생

온라인 버전은 내 Dropbox **앱 폴더**의 영상을 4시간짜리 임시 링크로 받아 재생합니다. 기기마다 처음 한 번 **Dropbox 연결**로 로그인하면, 그 뒤로는 재발급 토큰으로 알아서 이어집니다. 연결은 보관함 탭의 **연결 끊기**나 Dropbox 설정에서 기기별로 끊을 수 있습니다. 링크를 공개하지 않으므로 영상이 남에게 열리지 않습니다.

- 앱 폴더는 맥 라이브러리와 같은 구조로 둡니다(`S01/1x01 - ….mp4`와 `.en.srt`, `YouTube AI/… [영상id].mp4`). 영상 id가 맥 서버와 같아서 보관함·진도가 그대로 이어지고, 내려받아 둔 YouTube 영상은 목록에서 YouTube 버전을 대신합니다.
- 처음 설정: [Dropbox App Console](https://www.dropbox.com/developers/apps)에서 **Scoped access → App folder**로 앱을 만들고, Permissions에서 `files.metadata.read`와 `files.content.read`만 켭니다. Settings의 OAuth 2 Redirect URIs에 `https://hellbell.github.io/friends-english/`를 넣고, App key는 `index.html`의 `fe-dropbox` meta에 있습니다(앱 **wellvell-english-study**, 공개 값이며 PKCE 로그인이라 App secret은 쓰지 않습니다).
- 영상 올리기: 첫 연결 뒤 생긴 앱 폴더(`Dropbox/Apps/<앱 이름>`)에 라이브러리를 복사하고 `python3 prep.py <앱 폴더> --audio`로 소리만 파일을 만듭니다. 올라간 뒤에는 Finder에서 "온라인 전용으로 설정"하면 맥의 공간을 차지하지 않습니다.
- 아이폰 Safari는 이 사이트를 7일 넘게 열지 않으면 로그인 정보를 지울 수 있습니다. 홈 화면에 추가한 앱은 이 규칙을 받지 않습니다.

Dropbox 없이 볼 때는 영상과 자막을 기기에 내려받은 뒤 **내 영상·자막 열기**로 함께 선택하세요. 파일을 웹사이트에 올리지 않으며, 다음 방문에는 다시 선택해야 합니다. 브라우저에서 지원하는 MP4(H.264/AAC)를 권장합니다.

### 소리만 (화면을 꺼도 재생)

**소리만**을 켜면 같은 위치에서 영상 대신 소리만 재생합니다. 아이폰은 화면이 꺼지면 영상은 멈추지만 소리 재생은 이어서, 화면을 끄거나 다른 앱을 써도 계속 들립니다. 잠금 화면·이어폰 버튼으로 재생·정지와 이전·다음 문장을 조작합니다. Dropbox에 `.m4a`(소리만 파일)가 있으면 그것을 받아 데이터도 영상의 1/10쯤만 씁니다. YouTube로 재생하는 영상은 소리만 재생을 지원하지 않습니다.

### 배포와 추천 목록 갱신

```sh
python3 build_pages.py --set-password   # 비밀번호를 정하거나 바꿈: 잠금 키 저장 (GitHub 비밀값 PAGES_KEY도 설정)
python3 build_pages.py                  # dist/에 잠긴 사이트를 만듦 (Deno 필요: brew install deno)
python3 build_pages.py --refresh        # YouTube 공개 RSS를 읽어 새 영상 추가
python3 build_pages.py --public         # 잠금 없이 빌드: 이 맥에서 화면 확인용, 배포하지 말 것
python3 -m http.server 8766 --directory dist --bind 127.0.0.1
```

`dist/`에는 잠금 화면(`index.html`)과 아이콘, 그리고 **암호화된** 앱·추천 목록·준비된 한영 SRT만 들어갑니다. 앱·추천 목록·자막은 AES-256-GCM으로 암호화되어 비밀번호 없이는 읽을 수 없고, 그대로 보이는 것은 잠금 화면과 아이콘뿐입니다. 개인 영상, `downloads/`, 서버 상태와 보관함은 복사하지 않습니다.

- 비밀번호에서 PBKDF2-SHA256(60만 회)으로 잠금 키를 만듭니다. 키는 이 맥의 `~/Library/Application Support/FriendsEnglish/pages.key`와 GitHub 저장소 비밀값 `PAGES_KEY`(매일 배포용)에만 있고, 비밀번호 자체는 어디에도 저장하지 않습니다. `PAGES_KEY`가 없으면 빌드가 멈추고 배포하지 않습니다.
- 암호화된 파일은 누구나 받아 갈 수 있으므로 추측하기 어려운 비밀번호를 쓰세요. `--set-password`에서 Enter만 누르면 하나 만들어 줍니다.
- 로그인 유지 키와 진도는 브라우저 저장소에 있고, `hellbell.github.io` 아래 다른 Pages 사이트와 같은 저장소를 씁니다. 그 사이트들에 남의 스크립트를 넣지 마세요.

저장소(hellbell/friends-english)는 공개입니다. GitHub 무료 플랜은 비공개 저장소에서 Pages를 켤 수 없기 때문입니다. 그래서 잠금은 **사이트 접속**을 막고, 원본 코드·추천 목록·자막은 GitHub 저장소에서 그대로 보입니다(진도·단어장은 저장소에 없습니다). 이것까지 숨기려면 저장소를 비공개로 바꾸고 GitHub Pro를 쓰거나, 암호화된 `dist/`만 별도 공개 저장소로 배포해야 합니다.

- Settings → Pages → Source는 **GitHub Actions**입니다. `.github/workflows/pages.yml`이 `main` 갱신·수동 실행·매일 22:17 UTC(한국 07:17)에 잠긴 사이트를 배포하며, 저장소 비밀값 `PAGES_KEY`(잠금 키)가 있어야 합니다.
- 예약 실행은 지연될 수 있고, 공개 저장소가 오래 비활성이면 GitHub가 예약 실행을 멈출 수 있습니다. 피드 하나가 실패하면 해당 채널의 저장된 목록을 유지합니다. **목록 다시 읽기**는 마지막 배포된 목록을 가져옵니다.

`catalog.json`에서 직접 고른 영상과 추천 이유를 수정할 수 있습니다. `source: feed` 항목만 자동 갱신 대상이며, `curated`와 `prepared` 항목은 유지합니다. 피드에 없는 영상 길이·자막 유무·퍼가기 가능 여부는 추측하지 않습니다. YouTube에서 영상을 내리거나 퍼가기를 막으면 원본 링크로 확인하세요.

## 실행

    python3 serve.py ~/Movies/Friends          # http://localhost:8765 이 자동으로 열림

서버 없이 `index.html`을 바로 열고 "파일 열기"(또는 창에 끌어다 놓기)로 영상과 자막을 골라도 됩니다.
이 경우 진도와 보관함은 그 브라우저에만 저장됩니다. 추천 목록과 YouTube를 쓰려면 위 온라인 주소나 HTTP 서버로 여세요.

## 맥미니에서 상시 실행

    ./macmini.sh                 # 로그인하면 자동으로 켜지고, 죽으면 다시 켜짐. 코드를 고친 뒤 다시 실행하면 갱신
    ./macmini.sh --lan           # 집 Wi-Fi의 다른 기기에서도 http://<맥미니 IP>:8765 로 접속 허용
    ./macmini.sh --uninstall     # 자동 실행 해제

- 앱은 `~/Library/Application Support/FriendsEnglish/app`에 복사해서 실행합니다. Dropbox 폴더는 백그라운드 실행 시 권한 문제가 생길 수 있기 때문입니다.
- 진도, 보관함, 유튜브 목록은 `~/Library/Application Support/FriendsEnglish/state.json`에 저장됩니다. 로그는 `~/Library/Logs/friends-english.log`에 남습니다.
- 라이브러리는 `~/Movies` 아래에 두세요. 데스크톱, 문서, 다운로드, 외장 디스크는 macOS가 백그라운드 접근을 막을 수 있고, Dropbox 폴더는 실제로 막힙니다(정책상 거부, 허락 창도 뜨지 않음).
- 2026-11-11에 영상을 Dropbox 앱 폴더로 옮겨서 맥 서버의 라이브러리는 비어 있습니다. 맥에서도 온라인 버전으로 보세요. 맥 서버에 쌓인 진도·싱크 보정은 맥 서버의 **학습 백업 내보내기** → 온라인 버전의 **백업 가져오기**로 옮깁니다.
- 다른 프로그램이 `::1:8765`만 쓰고 있으면(예: `kubectl port-forward`) 함께 뜰 수 있지만, 그동안 브라우저의 `localhost:8765`는 그쪽으로 가므로 `http://127.0.0.1:8765`로 여세요.
- 맥미니는 로그인 상태를 유지하고, 시스템 설정에서 잠자기를 꺼 두어야 합니다.

### 밖에서(아이폰·회사) 쓰기: Tailscale

1. 맥미니와 아이폰·아이패드·노트북에 Tailscale을 설치하고 같은 계정으로 로그인합니다 (`brew install --cask tailscale` 또는 App Store).
2. 맥미니에서 `tailscale serve --bg 8765`를 실행합니다. 처음이면 관리 페이지에서 HTTPS를 켜라는 링크가 나옵니다.
3. 다른 기기에서 `https://<맥미니 이름>.<tailnet>.ts.net/`을 엽니다. 아이폰 Safari에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

내 Tailscale 계정에 로그인한 기기만 접속할 수 있고, 인터넷에 공개되지 않습니다.

## 라이브러리 폴더

    ~/Movies/Friends/
      Season 01/
        Friends.S01E01.(...).mp4
        Friends.S01E01.(...).en.srt          ← 영어 자막 (srt / vtt / smi)
        Subs/Friends - 1x01 - (...).ko.smi   ← 한글 자막 (선택)

- 같은 폴더(또는 하위 `Subs/`)에서 파일명 앞부분이나 에피소드 코드(`S01E01`, `1x01`)가 같으면 자동으로 짝지어집니다.
- 영어와 한글은 줄 내용으로 구분하므로 한영 통합 자막도 그대로 쓸 수 있습니다. 인코딩(UTF-8, UTF-16, CP949)도 자동으로 처리합니다.

## 유튜브

위쪽 칸에 유튜브 주소를 붙여넣고 "추가"를 누르면 됩니다. 영상은 받지 않고 유튜브 공식 플레이어로 재생합니다.
**맥 서버 모드에서** 영어 자막(+한국어 자막)은 맥미니가 yt-dlp로 가져와 문장 단위로 묶습니다 (`brew install yt-dlp`, 보통 10초~1분). 추천에서 연 영상은 "자막 가져오기"로 요청할 수 있습니다.

- 사람이 단 자막이 있으면 그것을, 없으면 자동 자막을 씁니다. 자동 자막은 문장 부호가 없는 경우가 많아 말의 쉼을 기준으로 5~14단어씩 끊습니다.
- 새 영상의 한국어는 유튜브 자동 번역입니다. 준비된 AI 영상의 한국어 자막은 GPT 번역입니다. 유튜브가 요청을 잠시 막으면(429) 새 자막이 빠질 수 있습니다.
- 퍼가기가 막힌 영상은 앱에서 재생할 수 없습니다. 유튜브가 자주 바뀌니 가끔 `brew upgrade yt-dlp`를 해 주세요.

## 영상·자막 준비: prep.py (ffmpeg 필요)

    python3 prep.py ~/Documents/원본폴더 --out ~/Movies/Friends   # mkv → mp4 (H.264면 무손실 복사), 내장 영어·한국어 텍스트 자막 → .en.srt/.ko.srt
    python3 prep.py ~/Movies/Friends --whisper ~/models/ggml-large-v3-turbo-q5_0.bin      # 영어 자막이 없는 영상에 자막 생성
    python3 prep.py ~/Movies/Friends --check-sync ~/models/ggml-large-v3-turbo-q5_0.bin   # 영어 자막 싱크 검사
    python3 prep.py ~/Movies/Friends --audio     # mp4마다 소리만 뽑은 .m4a (앱의 '소리만' 재생용, 재인코딩 없음)
    python3 prep.py ~/Movies/Friends --dry-run   # 실행할 명령만 출력

- 원본은 지우지 않습니다. `--out`을 주면 원본 폴더 구조 그대로 다른 폴더에 만들고, 없으면 원본 옆에 만듭니다. 같은 이름의 mp4가 생기면 앱 목록에서 mkv는 숨겨집니다.
- 내장 자막은 영어·한국어만 뽑습니다. 다른 언어(프랑스어 등)는 라틴 문자라 영어로 잘못 잡힐 수 있기 때문입니다. SDH(청각장애인용)는 일반 자막이 없을 때만 씁니다. DVD 이미지 자막(dvd_subtitle, PGS)은 텍스트로 뽑을 수 없으니 `--whisper`로 만드세요.
- Whisper 자막은 단어마다 실제 발화 시각(DTW)을 받아 문장 단위로 묶습니다 (`brew install whisper-cpp`).
- `--check-sync`는 영상의 앞·중간·뒤 90초씩을 받아써서 자막 첫 단어가 실제로 들리는 시각과 비교합니다. 맞지 않는 영상은 앱에서 `,` `.` 키로 보정하면 영상별로 저장됩니다.

모델(574MB)은 이렇게 받습니다.

    mkdir -p ~/models && curl -L -o ~/models/ggml-large-v3-turbo-q5_0.bin \
      https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin

## 공부 방법 (단축키 전체 목록은 앱에서 `?`)

- 따라 말하기: `P` (문장마다 멈춤) → 듣고 따라 말한 뒤 `Space`
- 모바일(화면 폭 900px 이하): **이전·다시·▶·다음·문장 저장** 막대가 화면 아래에 고정됩니다. 문장마다 멈춘 뒤 ▶나 영상을 눌러 이어 듣고, **☆ 문장 저장**으로 지금 문장을 보관함에 넣습니다.
- 반복 듣기: `L` (현재 문장 계속 반복), `↓` (한 번 더), `[` `]` (속도 조절)
- 대본 없는 구간 반복: 원하는 위치에서 **시작 A**, 끝 위치에서 **끝 B**, **A–B 반복**. 문장 반복·자동 멈춤과 함께 켜지지 않으며, 영상을 바꾸면 구간은 초기화됩니다.
- 자막 가리고 듣기: `H` → 흐림(재생 중에만 흐리고, 멈추거나 마우스를 올리면 보임) → 숨김
- 받아쓰기: 모바일에서 제대로 동작하지 않아 잠시 꺼 두었습니다 (`index.html`에서 주석 처리).
- 단어: 자막의 단어를 클릭(구문은 드래그) → 사전 / 보관함 저장 → 보관함 탭에서 TSV로 내보내 Anki에 가져오기
- 화면 크기: 영상 아래 막대는 위아래로 드래그해서 영상 높이 조절. 영상과 대본·보관함 사이의 세로 막대는 좌우로 드래그해서 오른쪽 패널 폭 조절 (두 번 클릭하면 기본 크기)
- 자막 크기: 영어·한국어를 각각 75~200%로 조절. 영상 높이·패널 폭·자막 크기는 브라우저에 자동 저장되며, “크기 초기화”로 모두 복원
- 자막이 소리와 어긋나면 `,` `.` 로 0.1초씩 맞춤 (영상별로 저장)

맥 서버 모드에서는 다른 기기에서 공부하다 돌아오면 앱 화면으로 돌아오는 순간 진도와 보관함을 다시 받아옵니다. GitHub Pages 버전의 진도는 백업 파일로 옮기고, 보관함은 동기화를 켜면 자동으로 이어집니다.
